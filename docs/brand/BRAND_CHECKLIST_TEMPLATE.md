# Brand Audit & Brand Identity — Checklist template (agence web / IA, 2026)

> Template vierge et réutilisable. Construit à partir de 4 checklists produites en parallèle (Gemini, ChatGPT, DeepSeek, Perplexity via le MCP search-ai), dédoublonnées et adaptées à une petite agence web/IA.
> Version remplie pour NeuraWeb : [BRAND_AUDIT_NEURAWEB_2026.md](BRAND_AUDIT_NEURAWEB_2026.md).

**Légende** — `P` priorité : 🔴 indispensable · 🟠 important · 🟡 recommandé.
`CR` = critère de réussite (comment savoir que c'est fini). `L` = livrable.
Statut : `[ ]` à faire · `[~]` en cours · `[x]` fait · `[n/a]` non applicable.

**Ordre d'exécution** : 1 Audit → 2 Stratégie → (validation go/no-go) → 3 Identité visuelle → 4 Guidelines → 5 Activation. Ne pas dessiner de logo avant la fin de la partie 2.

---

## 1. BRAND AUDIT (où en est la marque aujourd'hui ?)

### 1.1 Cadrage
- [ ] 🔴 Périmètre : marque, offres, sous-marques, marchés/langues. **CR** : une phrase de périmètre signée. **L** : brief d'audit
- [ ] 🔴 3 à 5 objectifs business mesurables (leads/mois, prix moyen, marchés, récurrence). **L** : objectives map
- [ ] 🔴 Baseline chiffrée *avant* changement : trafic, leads, conversion, CTR, position, avis, mentions IA. **L** : tableau de bord de départ
- [ ] 🟠 Budget, calendrier, décideur unique. **L** : plan de projet

### 1.2 Audit interne
- [ ] 🔴 Mission, ambition, modèle économique, offres qui rapportent vraiment (marge, récurrence). **L** : synthèse
- [ ] 🔴 Cartographie des offres et prix (redondances, trous, lisibilité). **L** : service portfolio map
- [ ] 🔴 10–20 projets passés : secteur, résultat, preuve disponible (chiffres, capture, témoignage, autorisation de publier). **L** : case-study matrix
- [ ] 🔴 Forces difficiles à copier (3–5), chacune avec une preuve. **L** : proof-point inventory
- [ ] 🔴 Écart promesse ↔ capacité réelle (délais, marges, disponibilité). **L** : promise-vs-delivery matrix
- [ ] 🟡 Culture / valeurs réellement vécues (pas seulement déclarées). **L** : note

### 1.3 Audit externe & marché
- [ ] 🔴 Segments servis et segments visés, classés par potentiel et fit. **L** : matrice de priorisation
- [ ] 🔴 Alternatives *réelles* du client : agences, freelances, ESN, no-code (Wix/Shopify), IA, équipe interne. **L** : paysage concurrentiel
- [ ] 🔴 8–15 concurrents, fiche standard : promesse, cible, offres, **prix publiés oui/non**, preuves, SEO, visuel, ton. **L** : scorecard
- [ ] 🟠 Part de voix : SEO, LinkedIn, annuaires, presse, communautés. **L** : classement vs 5 concurrents
- [ ] 🔴 Réputation : avis Google/Clutch/Trustpilot, mentions presse/forums. **L** : audit réputation
- [ ] 🔴 **Visibilité IA** : poser 10–20 requêtes cibles à ChatGPT, Perplexity, Gemini, AI Overviews ; noter qui est cité et pourquoi. **L** : AI visibility baseline
- [ ] 🟠 Tendances sectorielles (agents IA, GEO, no-code, prix). **L** : 5–10 tendances + implications

### 1.4 Perception client
- [ ] 🔴 5–15 entretiens (clients, prospects perdus) : déclencheur d'achat, alternatives, objections, décision. **L** : verbatims
- [ ] 🔴 Pains avant achat classés (fréquence × intensité). **L** : pain map
- [ ] 🔴 Jobs-to-be-done fonctionnels / émotionnels / sociaux (5–10, dans les mots du client). **L** : JTBD
- [ ] 🔴 Parcours d'achat : découverte → shortlist → devis → livraison → recommandation ; points de friction. **L** : journey map
- [ ] 🔴 Analyse des deals perdus. **L** : win/loss
- [ ] 🟠 Lexique client (mots exacts à réutiliser en copywriting). **L** : glossaire

### 1.5 Inventaire des assets
- [ ] 🔴 Tous les points de contact (site, blog, réseaux, emails, devis, contrats, signatures, démos, apps). **L** : touchpoint inventory
- [ ] 🔴 Logos et fichiers sources (vectoriel, versions claire/sombre, favicon, formats web) : existent-ils et sont-ils exploitables ? **L** : asset register
- [ ] 🟠 Contenus (pages clés, articles, études de cas, démos) classés par performance. **L** : content audit
- [ ] 🔴 Assets obsolètes / contradictoires (anciens logos, anciennes palettes, anciens domaines) → garder / mettre à jour / archiver. **L** : plan d'action

### 1.6 Cohérence & diagnostic
- [ ] 🔴 Promesse affichée ↔ perception client ↔ réalité (gap analysis). **L** : écarts documentés
- [ ] 🔴 Cohérence visuelle par canal (logo, couleurs, typo, photo, UI), note /5. **L** : audit visuel
- [ ] 🔴 Cohérence éditoriale (ton, vocabulaire, promesses, CTA), note /5. **L** : audit message
- [ ] 🔴 Test de distinctivité : si on masque le logo, reconnaît-on la marque ? **CR** : ≥ 3 éléments distinctifs identifiés. **L** : assessment
- [ ] 🔴 Quick wins / risques / chantiers priorisés + validation du go/no-go. **L** : rapport d'audit

## 2. STRATÉGIE DE MARQUE

### 2.1 Problème & résolution
- [ ] 🔴 Problème central du client en une phrase *du point de vue du client*. **L** : problem statement
- [ ] 🔴 Pains rationnels (prix, délai, qualité, dette technique, ROI) et émotionnels (peur de se faire avoir, perte de contrôle, honte du jargon). **L** : pain map
- [ ] 🔴 Ce que le client cherche vraiment (résultat + sentiment recherché). **L** : gains map
- [ ] 🔴 Comment l'offre résout chaque pain (1 pain → 1 réponse → 1 preuve). **L** : tableau pain/solution/preuve

### 2.2 Audience & personas
- [ ] 🔴 2–4 segments priorisés (1 principal). **L** : segmentation
- [ ] 🔴 Avatar/persona par segment : contexte, déclencheur, peurs, critères de choix, canaux, objections, budget. **L** : fiches persona
- [ ] 🟠 Anti-persona (clients à ne pas chercher). **L** : liste

### 2.3 Proposition de valeur & différenciation
- [ ] 🔴 Proposition de valeur (formule : pour [cible] qui [problème], NOM est [catégorie] qui [bénéfice], contrairement à [alternative]). **L** : value proposition
- [ ] 🔴 « Le plus » : 1 différenciateur principal, prouvable, difficile à copier + 2–3 secondaires. **CR** : testé contre chaque concurrent (« le font-ils ? »). **L** : UVP
- [ ] 🔴 Catégorie et cadre de référence (« agence web », « studio », « partenaire »…). **L** : positioning statement
- [ ] 🔴 Raisons de croire (preuves : chiffres, démos, avis, processus). **L** : reasons to believe

### 2.4 Mission, vision, valeurs
- [ ] 🔴 Mission (ce qu'on fait, pour qui, pourquoi), vision (où dans 5 ans), 3–5 valeurs avec comportements observables. **L** : brand foundation

### 2.5 Personnalité, voix, archétype
- [ ] 🔴 5–7 attributs de marque (+ « jamais » : 3 anti-attributs). **L** : brand attributes
- [ ] 🟠 Archétype dominant + secondaire. **L** : note d'archétype
- [ ] 🔴 Tone of voice : curseurs (formel↔familier, sérieux↔humour, technique↔simple), mots à utiliser / à bannir, exemples avant/après, déclinaisons FR/EN/ES/VI. **L** : guide éditorial

### 2.6 Core strengths
- [ ] 🔴 3–5 forces fondamentales, chacune avec preuve et bénéfice client. **L** : core strengths

### 2.7 Messaging
- [ ] 🔴 Tagline (3 options testées), promesse, elevator pitch 10 s / 30 s / 2 min, boilerplate, bio réseaux (par réseau). **L** : messaging house
- [ ] 🟠 Messages par persona et par service. **L** : matrice messages
- [ ] 🟠 Architecture de marque (marque unique / sous-marques / offres nommées). **L** : schéma

> ✅ **Gate go/no-go** : la partie 2 doit être validée avant toute création visuelle.

## 3. IDENTITÉ VISUELLE

### 3.1 Plateforme créative
- [ ] 🔴 Concept visuel en une phrase, mots-clés d'ambiance (3), moodboard, « ce que ça n'est pas ». **CR** : chaque choix suivant se justifie par le concept. **L** : plateforme créative

### 3.2 Logo & signatures
- [ ] 🔴 Logo principal horizontal (symbole + nom)
- [ ] 🔴 Logo empilé (vertical)
- [ ] 🔴 Symbole seul (avatar réseaux, app, favicon)
- [ ] 🔴 Logotype seul (sans symbole)
- [ ] 🔴 Versions : couleurs de marque · noir · blanc · fond sombre · fond clair · monochrome
- [ ] 🔴 Favicon 16/32/48/180/512 + maskable + monochrome
- [ ] 🔴 Zone de protection, taille minimale (print/web), 6–8 usages interdits
- [ ] 🟠 Version animée (intro, loader)
- [ ] 🔴 Formats : SVG, PNG transparent, PDF, WebP ; **CR** : lisible à 16 px et en niveaux de gris. **L** : pack logo

### 3.3 Couleurs
- [ ] 🔴 Palette : 1 primaire, 1 accent signature, 1–2 secondaires, neutres, sémantiques (succès/erreur/alerte/info)
- [ ] 🔴 Valeurs HEX, RGB, CMYK, HSL + noms parlants + variables CSS/Tailwind
- [ ] 🔴 **Contrastes WCAG AA** mesurés pour chaque couple texte/fond (4,5 pour le texte, 3 pour le gros texte/UI) ; couples interdits listés
- [ ] 🔴 Ratios d'usage (ex. 60/30/10) et règles d'accent (où le corail/accent est autorisé)
- [ ] 🟠 Test de non-confusion : la palette évoque-t-elle une autre profession (banque, santé, BTP, restauration, crypto) ?
- [ ] 🟠 Connotations culturelles des couleurs par marché cible. **L** : color system

### 3.4 Typographie
- [ ] 🔴 Police principale (titres), secondaire (texte), tertiaire (mono/chiffres/étiquettes) ; licences libres ou achetées
- [ ] 🔴 **Support des diacritiques de toutes les langues du site** (ex. vietnamien) vérifié sur la fonte exacte
- [ ] 🔴 Échelle (H1→caption), interlignes, graisses, longueur de ligne, chargement web (subsets, `display: swap`)
- [ ] 🟠 Règles d'accent typographique (mot en italique/couleur dans les titres). **L** : type system

### 3.5 Système graphique
- [ ] 🔴 Formes, rayons, ombres, bordures, grille, espacements
- [ ] 🔴 Motifs / patterns (2–4) avec règles d'usage
- [ ] 🟠 Éléments décoratifs signature (ligne, forme, repère) = *distinctive brand assets*
- [ ] 🟠 Motion : durées, easings, animations autorisées, `prefers-reduced-motion`. **L** : graphic system

### 3.6 Illustrations, icônes, stickers
- [ ] 🔴 Style d'illustration (traits, remplissages, couleurs autorisées)
- [ ] 🔴 Set d'icônes personnalisé (24–48 px, trait homogène) pour services, secteurs, processus
- [ ] 🟡 Stickers / badges / tampons (réseaux, packaging de livrables)
- [ ] 🟠 Tags & étiquettes éditoriales (catégories blog, statuts, « Nouveau », « Populaire »)

### 3.7 Photographie & vidéo
- [ ] 🔴 Direction photo (lumière, cadrage, sujets, retouche, ce qu'on évite : banques d'images génériques)
- [ ] 🟠 Portraits de l'équipe, lieux de travail réels, preuves visuelles
- [ ] 🟡 Direction vidéo (format, sous-titres FR/EN/VI)

### 3.8 Applications
- [ ] 🔴 Réseaux : photo de profil par réseau, bannières (LinkedIn, Facebook, YouTube, X), **highlight covers** Instagram, templates post/story/carrousel LinkedIn
- [ ] 🔴 Signature email, modèle de devis/facture/contrat, deck commercial, template de présentation
- [ ] 🟠 Papeterie : carte de visite, en-tête, tampon
- [ ] 🟠 Mockups : écrans, mobile, carte, signalétique
- [ ] 🟠 Composants UI (boutons, cartes, formulaires, chips, tags) en variables de design / Storybook-like
- [ ] 🔴 Images de partage (OG 1200×630) et favicon dans le site. **L** : kit d'application

---

## 4. BRAND GUIDELINES
- [ ] 🔴 Sommaire : à propos · stratégie · logo · couleurs · typo · système graphique · imagerie · ton · applications · do/don't
- [ ] 🔴 Exemples bon / mauvais pour chaque règle
- [ ] 🔴 Fichiers sources organisés (`/logo`, `/color`, `/type`, `/templates`, `/social`) + convention de nommage + versionnage
- [ ] 🟠 Version lisible par une IA (Markdown/JSON : tokens couleurs, polices, ton) pour la génération de contenu cohérent
- [ ] 🔴 **Brand kit Canva/Figma** configuré (couleurs, polices, logos) — **L** : lien partageable
- [ ] 🔴 Checklist de validation finale (cohérence, accessibilité, fichiers complets)

---

## 5. ACTIVATION & GOUVERNANCE
- [ ] 🔴 Déploiement ordonné : site (header/footer/favicon/OG) → emails & documents → réseaux → annuaires/profils (Google Business, Clutch, LinkedIn) → démos/clients
- [ ] 🔴 Mise à jour des données structurées (Organization `logo`, `sameAs`), `llms.txt`, profils tiers (cohérence NAP et description)
- [ ] 🔴 Plan de contenu de lancement (annonce, étude de cas, vidéo fondateur) sur 30 jours
- [ ] 🔴 KPIs : notoriété (recherches de marque GSC), part de voix, mentions IA, taux de conversion, avis, prix moyen vendu
- [ ] 🟠 Revue trimestrielle (cohérence, nouveaux assets, dérives, retour client)
- [ ] 🟠 Règles de gouvernance : qui valide, où sont les sources, quand on fait évoluer la marque
