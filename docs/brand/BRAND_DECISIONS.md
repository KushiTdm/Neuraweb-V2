## Points ouverts
- La palette multi-teintes de [BRAND_COLOR_TYPE_STRATEGY.md](BRAND_COLOR_TYPE_STRATEGY.md) a été pensée avec un bouton **Sable** `#F3AC5E`. Sur l'accueil bicolore, le bouton est plein Chypre (ou Crème sur fond vert). **À trancher** : le bouton reste-t-il Sable sur les pages thématiques ?
- Polices : le serif rétro du logo correspond à l'**option B** (Fraunces Black) ; l'accueil bicolore proposait Inter Tight + Lora. **À trancher** : une seule famille de titres pour tout le site ?
- Le logo P3 est une image générée : il doit être redessiné en SVG (vraie police, `w` décoré) avant intégration.
