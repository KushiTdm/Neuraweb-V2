# Contexte Neuraweb

## L'agence
Neuraweb est une agence française spécialisée en automatisation IA et transformation
digitale pour PME, fondateurs SaaS et responsables marketing.

## Positionnement
- Automatisation concrète (pas de théorie)
- Stack réelle : n8n, Claude API, Airtable, Make
- Clientèle : PME françaises, fondateurs, freelances tech
- Différenciateur : on montre les workflows, on ne vend pas du rêve

## Ton éditorial
Expert mais accessible · Concret · Résultats · Pas de jargon inutile
Jamais donneur de leçon · Jamais bullshit de consultant

## Stack technologique
- **Frontend** : Next.js 16, React, TypeScript, Tailwind CSS
- **Backend** : Node.js, Supabase (PostgreSQL)
- **Intégrations** : Stripe (paiement), Resend (email), Claude API, n8n, Make
- **Mobile** : React Native (cross-platform), Native iOS (Swift), Android (Kotlin), Flutter
