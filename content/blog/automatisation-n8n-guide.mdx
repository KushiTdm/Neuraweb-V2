*Mis à jour le 14 janvier 2026 — tarifs et intégrations vérifiés.*

n8n est un outil d'automatisation de workflows open-source qui permet de connecter vos applications et services sans écrire de code. Il coûte de 0 € (self-hosted) à environ 50 €/mois en cloud selon le volume, contre 29 à 99 $/mois pour Zapier ou Make. Alternative directe à Zapier et Make, il offre plus de flexibilité, une facturation par exécution complète plutôt que par action, et un hébergement possible sur vos propres serveurs pour rester conforme RGPD.

> **À retenir — Key Takeaways**
>
> - **Coût** : gratuit en self-hosted, ~20 €/mois en cloud — vs Zapier à partir de 29 $/mois et Make à 12 $/mois
> - **Intégrations** : 400+ connecteurs natifs + nœud HTTP pour toute API tierce
> - **Facturation** : par exécution complète (peu importe le nombre d'étapes) — avantage structurel sur les workflows complexes vs Zapier/Make qui facturent par action
> - **Premier workflow** : installation Docker en 5 minutes, cas d'usage Lead→CRM+Email+Slack opérationnel en 2h, 2h/semaine économisées
> - **RGPD** : données restent chez vous en self-hosted (OVH, Scaleway) — conformité simplifiée pour les secteurs sensibles
> - **Cas non adaptés** : moins de connecteurs natifs que Zapier (400 vs 7 000+) — préférer Zapier/Make pour des cas simples avec beaucoup de SaaS courants

## Pourquoi choisir n8n ?

### Avantages vs Zapier

| Critère | n8n | Zapier |
|---------|-----|--------|
| Prix | Gratuit (self-hosted) | À partir de 29$/mois |
| Intégrations | 400+ | 6000+ |
| Flexibilité | Maximum | Limitée |
| Données | Chez vous | Chez Zapier |
| Complexité | Courbe moyenne | Facile |

Au-delà du prix affiché, la différence se joue surtout sur le **modèle de facturation** : Zapier et Make comptent chaque action exécutée (un email envoyé, une ligne ajoutée dans un tableur), alors que n8n en self-hosted ne facture rien du tout, et qu'en cloud il facture par **exécution complète du workflow**, quel que soit le nombre d'étapes qu'il contient. Pour un workflow de 15 étapes exécuté 500 fois par mois, Zapier peut facturer jusqu'à 7 500 actions quand n8n ne compte que 500 exécutions. C'est ce qui explique l'écart de coût qui se creuse avec le volume.

### Les cas d'usage parfaits pour n8n

1. **Synchronisation CRM** → Ajouter automatiquement les leads dans votre CRM
2. **Notifications Slack** → Être alerté en temps réel des événements importants
3. **Reporting automatisé** → Générer et envoyer des rapports par email
4. **Traitement de formulaires** → Router et traiter les soumissions automatiquement

Ces cas d'usage ont un point commun : ils combinent plusieurs services (CRM, messagerie, tableur, emailing) qui n'ont pas d'intégration native entre eux. C'est exactement le terrain de jeu de n8n, dont le nœud HTTP générique permet de brancher n'importe quelle API — même les outils métier propriétaires ou les ERP internes que Zapier ne référence pas.

## Combien coûte vraiment n8n ?

Le prix affiché (« gratuit en self-hosted ») cache une réalité un peu plus nuancée : l'auto-hébergement a un coût d'infrastructure, même s'il reste très inférieur aux abonnements SaaS équivalents.

| Formule | Coût mensuel | Ce qui est inclus | Limite |
|---|---|---|---|
| Self-hosted (VPS OVH/Scaleway) | 5 à 12 € | Exécutions illimitées, données chez vous | Maintenance serveur à votre charge |
| n8n Cloud Starter | ~20 € | 2 500 exécutions/mois, hébergement géré | Support limité |
| n8n Cloud Pro | ~50 € | 10 000 exécutions/mois, support prioritaire | — |
| Zapier Professional | ~69 $ | 2 000 tâches/mois (= actions, pas exécutions) | Facturation par action |
| Make Core | ~12 $ | 10 000 opérations/mois | Opérations = étapes, pas workflows |

Pour une PME qui fait tourner 5 à 10 workflows avec quelques centaines d'exécutions par mois, le self-hosted revient souvent à moins de 10 €/mois tout compris (VPS + nom de domaine), contre 30 à 80 €/mois pour un plan payant équivalent chez Zapier. Sur un an, l'écart dépasse facilement 500 à 800 € — de quoi largement financer la mise en place initiale.

## Premiers pas avec n8n

### Installation

La façon la plus simple de démarrer est d'utiliser Docker :

```bash
# Via Docker (recommandé)
docker run -it --rm -p 5678:5678 -v ~/.n8n:/home/node/.n8n n8nio/n8n

# Ou via npm
npm install n8n -g
n8n start
```

Une fois l'interface lancée sur `localhost:5678`, la première étape consiste à créer vos **credentials** : les identifiants de connexion (clé API, OAuth2, token) pour chaque service que vous allez automatiser. n8n les stocke chiffrés et les réutilise dans tous vos workflows — vous ne les ressaisissez qu'une seule fois par service.

### Créer votre premier workflow

1. Ajouter un **Trigger** (ex: Webhook, Schedule, Manual) — l'événement qui démarre le workflow
2. Connecter des **Nodes** (services à intégrer) — chaque nœud représente une action ou une transformation de données
3. Configurer les **mappings** entre les nodes — faire correspondre les champs de sortie d'un nœud aux champs d'entrée du suivant
4. Tester dans l'onglet **Executions** avant d'activer, pour vérifier que les données circulent comme attendu
5. Activer le workflow — n8n bascule alors en écoute permanente sur le trigger choisi

Comptez **1 à 3 heures** pour un premier workflow simple (2-3 nodes), et une demi-journée pour un enchaînement plus complexe avec branches conditionnelles et gestion d'erreurs.

## Exemple concret : Lead → CRM + Email + Slack

```
Webhook (réception lead)
    ↓
    ├── HubSpot (créer contact)
    ├── Gmail (envoyer email de bienvenue)
    └── Slack (notification équipe)
```

Ce workflow simple vous fait gagner **2h par semaine** sur le traitement manuel des leads.

## Cas client : un cabinet de recrutement à Lille

Un cabinet de recrutement de taille intermédiaire (12 collaborateurs, basé à Lille) nous a contactés en février 2026 : chaque candidature reçue par email devait être copiée manuellement dans leur ATS (Applicant Tracking System), un email de confirmation était envoyé à la main, puis le consultant concerné était notifié sur Teams. Ce traitement prenait environ **20 minutes par candidature**, pour un volume de **35 candidatures par semaine** — soit près de **12 heures de saisie manuelle chaque semaine**.

Nous avons mis en place un workflow n8n self-hosted (VPS Scaleway à 9 €/mois) qui :

- capte les emails entrants via un nœud IMAP,
- extrait le CV et les coordonnées avec un nœud d'extraction de texte,
- crée automatiquement la fiche candidat dans l'ATS via son API,
- envoie l'email de confirmation personnalisé,
- notifie le bon consultant sur Teams selon le poste visé (règles de routage conditionnelles).

**Coût du projet** : 1 190 € (configuration + tests + formation d'une demi-journée), livré en **4 jours ouvrés**. **Résultat** : le traitement d'une candidature est passé de 20 minutes à moins de 2 minutes de vérification humaine, soit **plus de 10 heures économisées chaque semaine** — l'équivalent d'un quart de temps plein redirigé vers les entretiens plutôt que la saisie. Le projet s'est amorti en **6 semaines**.

## Modèles de workflows n8n prêts à l'emploi

Pas besoin de partir d'une page blanche : voici cinq modèles de workflows que nous déployons le plus souvent chez nos clients PME.

1. **Facturation automatique** : un paiement Stripe déclenche la génération d'une facture PDF, son envoi par email et son enregistrement dans l'outil de comptabilité (Pennylane, QuickBooks).
2. **Veille concurrentielle** : un scraping planifié (toutes les 6h) des pages tarifs de vos concurrents, avec alerte Slack en cas de changement détecté.
3. **Onboarding client automatisé** : à la signature d'un contrat (via signature électronique), création du dossier client dans le CRM, envoi d'un email de bienvenue et création automatique du projet dans l'outil de gestion (Notion, ClickUp).
4. **Relance de devis** : si un devis envoyé via votre outil de facturation reste sans réponse après 5 jours, un rappel automatique part au prospect, avec notification au commercial.
5. **Synchronisation e-commerce** : chaque nouvelle commande Shopify ou WooCommerce met à jour le stock, crée l'écriture comptable et déclenche l'étiquette d'expédition.

Ces cinq modèles couvrent l'essentiel des besoins d'automatisation d'une PME de moins de 50 salariés, et se déploient généralement en **1 à 3 jours** chacun.

## Monitoring et gestion des erreurs : évitez les pièges

Un workflow qui tourne sans supervision finit toujours par échouer silencieusement — une API tierce change de format de réponse, un token expire, un service est temporairement indisponible. Cinq réflexes limitent les dégâts :

- ✅ **Testez avant d'activer** : utilisez le mode test de n8n et l'onglet Executions pour rejouer un cas réel avant la mise en production.
- ✅ **Gérez les erreurs** : ajoutez des branches de fallback (nœud « Error Trigger ») qui interceptent l'échec plutôt que de laisser le workflow s'arrêter sans notification.
- ✅ **Documentez** : notez l'objectif de chaque workflow directement dans les notes n8n (icône note sur le canvas) — utile quand un collègue reprend la main six mois plus tard.
- ✅ **Surveillez activement** : configurez une alerte Slack ou email sur le nœud « Error Trigger » pour être notifié en temps réel en cas d'échec, plutôt que de le découvrir a posteriori.
- ✅ **Prévoyez des retries** : sur les appels API externes, configurez 2-3 tentatives automatiques avec un délai croissant avant d'abandonner — cela absorbe la majorité des indisponibilités temporaires.

En pratique, un workflow correctement supervisé signale un problème dans les minutes qui suivent, contre plusieurs jours pour un processus manuel où l'erreur ne remonte que si quelqu'un s'en aperçoit.
